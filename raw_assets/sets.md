# Asset sets

**A set is a family of assets with a like style and a like function**, kept so a new model finds what already belongs
with it. It is a reuse hint, not a fence: a model draws from as many sets as it needs, an asset sits in every set it
suits, and a face, a decal or a part worn outside every set of its model is named by `qq shapes library` for a second
look, never refused. Materials (`kind: material`) are worn anywhere. The catalogue and the rules are
[index.md](index.md#the-catalogue); a set is added here, by a row, when a family appears that none of these is.

| set | style and function |
|---|---|
| `issue_steel` | The Company's issue hardware every device is built from: enamelled and bare steel, dark trim, pipe, plain panels, plates and labels. |
| `controls` | Gear one operator reads and works: control panels, green phosphor screens, dial gauges, indicator lamps, handwheels, latches. |
| `airworks` | Air and water handling: fans and grilles, louvred vents, pleated filters, gas bottles, condensers, hoses. |
| `galley` | Food and drink: worktops, hotplates, steel sinks, dish racks, washers, mugs and jugs. |
| `hygiene` | Washing and the toilet: glazed ceramic, moulded plastic, mirrors, towelling, basins and bowls. |
| `quarters` | Living and rest: bunks, padded and quilted upholstery, canvas, tables, chests and lockers. |
| `growing` | Plants and cultures behind glass: tinted tanks and jars, culture liquid, grow lamps, sprouts, seed trays. |
| `workshop` | Making and mending: work benches, drawers, tool trays, motors, kilns, welded drums, perforated plate, charcoal. |
| `hull` | The capsule itself: wall caps and faces, kick strips, hazard stripes, access and floor hatches. |
| `power` | Power gathered and carried: solar cells, cable and hose runs. |
| `space` | What lies beyond the hull, behind the ship: star fields, nebulae, far galaxies. |
| `console` | The operator's page round the ship: window housings, label plates, keys, screen bezels, the console's steel and hazard trim — sliced and repeated, never stretched (GAM-14). |
